# Front-end: Beauty Booking

Клієнтська частина застосунку онлайн-запису. Чистий HTML + CSS + JavaScript (ES-модулі),
без фреймворків і без збірки — достатньо будь-якого статичного сервера.

## Запуск

```bash
# 1. Бекенд (у сусідній папці)
cd backend && pip install -r requirements.txt && python seed.py && uvicorn app.main:app --reload

# 2. Фронтенд
cd frontend
python -m http.server 5173          # або: npm start
```

Відкрити http://127.0.0.1:5173.

> Сторінку треба відкривати саме через сервер, а не подвійним кліком по `index.html`:
> браузери не завантажують ES-модулі з `file://`.

**Адреса API** — за замовчуванням `http://127.0.0.1:8000`, інша задається параметром:
`http://127.0.0.1:5173/?api=http://192.168.0.10:8000`.

**Демо-режим.** Якщо бекенд не відповідає, фронт автоматично працює на вбудованому
демо-API (`js/mock.js`) з тими самими даними й правилами, що й `backend/seed.py`; дані
зберігаються в `localStorage`, зверху показується жовта смуга з кнопкою «Скинути дані».
Примусово: `?mock`. Зручно для демо на парі й для QA без запущеного сервера.

## Що реалізовано (картки Trello)

| Картка | Сторінка | Що робить |
|---|---|---|
| FE-01 | `#/`, `#/master/:id` | Адаптивний каталог майстрів із фільтром за спеціалізацією; сторінка майстра зі списком послуг, тривалістю й цінами |
| FE-02 | `#/book/:master/:service`, крок 1 | Календар на 30 днів: дні з вільним часом підсвічені (`/available-dates`), решта неактивні; гортання місяців |
| FE-03 | там само, крок 2 | Слоти на обраний день (`/slots`) з урахуванням тривалості послуги, згруповані на ранок/день/вечір, із часом завершення |
| FE-04 | там само, крок 3 → `#/success/:code` | Форма імені й телефону з валідацією (ті самі правила, що в бекенді); екран успіху з кодом запису й кнопкою копіювання. Якщо слот щойно зайняли (409) — список оновлюється і клієнт обирає інший час |
| FE-05 | `#/check`, `#/check/:code` | Перевірка запису за кодом і скасування з підтвердженням |
| FE-07 | `#/cabinet` | Кабінет майстра: вибір майстра, список послуг, додавання послуги, додавання робочих годин на діапазон дат і дні тижня, огляд вільних днів на 2 тижні. Вхід за адмін-токеном (`X-Admin-Token`, за замовчуванням `admin-secret`) |

Адаптивність: mobile-first, перевірено на 390 px (телефон) і 1280 px (десктоп).
Доступність: семантичні кнопки/форми, `aria-pressed`/`aria-invalid`/`aria-live`, фокус із клавіатури,
`prefers-reduced-motion`.

│   ├── utils.js            дати, час, ціни, валідація телефону
│   ├── components/
│   │   ├── calendar.js     FE-02

│   └── views/
│       ├── catalog.js      FE-01

## Тести

```bash
cd frontend
node --test        # або: npm test   (Node 18+)
```

Покривають форматування дат/цін, валідацію імені й телефону, сітку календаря, групування слотів,
генерацію вільних слотів і сценарії демо-API: бронювання, конфлікт 409, валідацію 422,
скасування, адмін-доступ і додавання графіка.

## Обмеження

- Адмін-API бекенду не має ендпоінтів для перегляду, редагування й видалення графіка та послуг,
  тому в кабінеті їх можна лише додавати. Токен перевіряється під час першої дії, а не при вході.
- Окремих облікових записів майстрів немає: кабінет працює з будь-яким майстром за спільним токеном.
